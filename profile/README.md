# BeeLeap

   > 基岩版 Minecraft 服务器的**插件、资源包与运维工具**开发组织。
   > 平台：BDS + [LeviLamina](https://github.com/LiteLDev/LeviLamina) + LegacyScriptEngine（QuickJS / Node.js）

   ## 我们做什么

   把一整套**生存服运营所需的能力**做成可独立部署、可单独缺失、可网页管理的模块：

   | 方向 | 内容 |
   | --- | --- |
   | 🎮 服务端插件 | 核心玩法管线（每日任务、主城保护、禁言、在线时长、跨服）、VIP/头衔与飞行、TPA/Home/Warp、右键坐下、侧边栏与 TPS/MSPT、投票、白名单绑定、背
 包查看 |
   | 🛒 商城系统 | 官方商店与物品回收、玩家开店、个人仓库、悬赏求购、限时折扣、批量改价、交易提醒；支持从旧版商城**一键迁移生产数据** |
   | 🖥️ Web 管理面板 | 服务端内嵌 HTTP 服务 + 静态前端：实时概览、商店购买、按插件分页的管理后台、账号密码权限、演示模式 |
   | 🎪 活动玩法 | 波次守点活动、强化怪物 AI 行为包、活动部署包 |
   | 🎨 资源包 / 行为包 | DogeUI 界面美化（表单/菜单/开始界面）、装备与坐姿行为包 |
   | 🔧 协议与工具 | C++ 协议层探针（ProtocolLib 系列）、spark 脚本、数据导出与构建脚本 |

   ## 技术栈

   - **语言**：JavaScript（QuickJS / Node.js）、C++、Python、UI JSON
   - **服务端**：BDS、LeviLamina、LegacyScriptEngine 双引擎（`lse-quickjs` / `lse-nodejs`）
   - **前端**：原生 HTML / CSS / JS，无框架依赖，服务端零第三方 npm 依赖
   - **数据**：JSON 文件存储 + 版本迁移，旧数据自动导入
   - **测试**：用 stub 在 Node 里加载**真实插件**、驱动**真实表单回调**做端到端冒烟测试
     （单仓覆盖 300+ 断言：交易经济、防刷物品、页面布局、图标校验）

   ## 工作方式

   - **模块化拆分**：核心插件按职责拆成多个独立插件，任一缺失都不影响其余功能
   - **接口契约**：插件之间、插件与面板之间走统一命名空间导出，带白名单校验
   - **修 bug 必补测试**：每个线上问题都会沉淀成一条回归用例
   - **文档随代码走**：每个插件都有 README，记录配置、接口、迁移与已知限制
